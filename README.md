# robotics-learning-journey

Documenter, étape par étape, mon apprentissage de la robotique — du poste de
travail Linux jusqu'à un bras robotique fonctionnel en simulation et sur
matériel réel, avec ROS 2 comme colonne vertébrale.

## Technologies étudiées

- **Environnement & outils** : Ubuntu 24.04 LTS, Git/GitHub
- **Langages** : C++ (orienté objet, gestion mémoire), Python
- **Robotique** : ROS 2 (Jazzy Jalisco)
- **Modélisation & simulation** : URDF, TF2, RViz, Gazebo Sim
- **Perception** : vision par ordinateur, tri d'objets
- **Électronique** : microcontrôleur ESP32, passage à un système réel
